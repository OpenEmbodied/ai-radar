# Radar · 2026-11-14

## Signals

- **Harness design decides how well frontier models drive robots.**
  - Reins gives an off-the-shelf model 3D perception tools and atomic actions that report contact and grip, and lets it chain actions guarded by conditions in one call while a second "narrator" instance watches the cameras. GPT-6.1 Sol succeeds in 88% of real dual-arm episodes on five tasks; without the harness it fails every shell game (first-party).
  - JustRUA takes robot-use agent designs apart one at a time. A lean harness that keeps full episode history and stops motions early, plus scene geometry, raises the RoboDojo simulation score from 29.7 to 50.3 with no learned policy (first-party).
- **Agents that leave something reusable behind.**
  - ACE-CaP-0 has a coding agent refine real-world code policies, with demonstrations on request and simulation on demand, then freezes them: 92.1% success (221/240) on eight tasks with nobody in the loop (first-party).
  - H2E distills the sessions of an LLM agent into the VLA it calls, so the VLA navigates alone (REVERIE-CE 35.0% to 44.9%, first-party).
- **Infrastructure built for coding agents.**
  - Alloy, an open multi-material physics engine, exposes itself as MCP tools and was written to be installed and driven by coding agents.
  - Robo-SWE gives coding agents 236 executable issues from robotics repositories, ROS 2 among them; resolve rates run from 43.9% to 56.5% (first-party).
- **Memory and safety in deployment.** HeMeR reuses KV-cache across an embodied agent's changing memory (NeurIPS 2026 oral). CGEM remembers only the events that change the odds of success. A humanoid deployment report finds that pressing the e-stop makes the robot fall, and argues for granting force authority in stages.
- **arXiv catch-up.** Thursday's batch was merged into Friday's listing (106 cs.RO entries), so this run covers both.
