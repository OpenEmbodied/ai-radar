# Radar · 2026-11-17

## Signals

- **Robot use as a post-training skill.** "Training Reasoning Models in Simulation to Natively Use Real Robots" trains an open-weight 27B reasoning model with robot-use reinforcement learning, entirely in simulation and without demonstrations. Like a computer-use agent, it reasons and then emits the next end-effector pose, with no harness. It reports the following (first-party):
  - LIBERO success rises from 1.6% to 74.4%, approaching GPT-6 Astra and GPT-6.1 Sol.
  - It succeeds in 60% of trials on a real dual-arm robot, where the base model never does.
  - Given a new task in a familiar scene on LIBERO-Pro, it reaches 57.4% against 0.75% for a fine-tuned π0.5.
  - It shows no measurable loss on nine reasoning, coding and vision benchmarks.

  Until now, strong robot-use agents have relied on frontier models wrapped in harnesses (Reins, JustRUA, AMP1).
- **A name for the paradigm.** "Envisioning Agentic Robotics" argues that a foundation model plus an embodied harness, which it calls "Embodied System 2", is the decision core of agentic robotics. It proposes evaluating model capability and closed-loop system performance separately, and sets out a roadmap from executing single primitives to filling standing roles.
- **Agents improving the policies they call.**
  - ESI post-trains an LLM-VLA agent as one unit, refining its prompts, its shared skill interface and its VLA weights from the agents' own corrections and handoffs. It reaches 49.41% success on ten RoboDojo tasks, above AgiBot's GO-3 Nano Preview Agent+WAM reference at 36.60% (first-party).
  - Agentic-Teacher has a coding agent write demonstration generators aimed at a VLA's failure states, lifting π0 on LIBERO-10 from 79.4% to 87.8% (first-party).
