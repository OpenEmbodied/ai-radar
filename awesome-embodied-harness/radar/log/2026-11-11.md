# Radar · 2026-11-11

## Signals

- **An entrance exam for robot coding agents.** Embodied First Exam gathers 1,156 tasks in 35 suites on 47 robots, and lets each coding agent choose how to act: direct control, writing code, or training a policy. Its realistic setting gives only sensor observations and no resets, a real-time variant keeps the world moving while the agent thinks, and a privileged setting gives an approximate upper bound.
- **Safety now crosses the digital-physical boundary.** ArmedAgent tests coding agents that control a real arm zero-shot. It covers malicious use enabled by frontier-model knowledge, and indirect prompt injection from web pages or email that turns into physical action, and finds substantial risks under widely used agent frameworks.
- **How far simple memory goes.** SimplEvo has GPT-6 Astra write a task memory from one demonstration and refine a text working memory after each training episode, with no weight updates and no post-trained policies. Under direct control this lifts EBench from 46.7% to 81.7% and tops the RoboDojo leaderboard (first-party). WICL (RoboScript) rehearses a task in simulation, writes the feedback into a task memory, and reaches 83.4% on RoboTwin 2.0 from one demonstration per task (first-party).
- **Self-improvement becomes selective, and monitors keep learning.**
  - ReSkill revises only the failing stages or skills, validates each change with paired full-task comparisons, and produces a policy that runs without the agent (62/80 real trials, first-party).
  - Flip Anything has a coding agent learn bimanual object flipping in simulation, raising success from 24.7% to 95.0% (first-party).
  - Streaming Failure Forecasting keeps refitting its monitor's last layer after deployment.
  - WeightSmith fixes a VLA's misreading of an instruction with a closed-form weight edit (first-party).
