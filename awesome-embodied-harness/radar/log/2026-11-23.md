# Radar · 2026-11-23

## Signals

- **The agent-to-ROS tool layer gets security fixes.** ROSA v1.0.11 (18 Nov) fixes three advisories, per its release notes: command injection through roslaunch arguments in both its ROS 2 and ROS 1 tools, and path traversal or arbitrary file reads in `read_log`, which is now limited to ROS log directories. LLM agents that drive robots through tool calls inherit the attack surface of those tools. This complements the configuration-layer attack on an LLM-controlled social robot logged on 2026-11-19.
- **Promised code landed.** XInfer, X Square Robot's production VLA serving system, now has a public repository with real-time chunking and fleet serving. It had not resolved on 2026-11-14.
- **An agent runtime goes read-only.** GitHub shows OpenMind's OM1 repository as archived since 14 Nov.
- **Watched repositories.** Genesis v1.4.7 (17 Nov) makes every solver deterministic on request. MuJoCo 4.0.1 was already noted last week. LeRobot, openpi, Isaac-GR00T, Isaac Lab, ManiSkill, ros-mcp-server, RAI and dimOS have no new releases.
- **arXiv:** Monday's listing had not been published when this run finished (checked until about 01:45 UTC). It falls into the next run's window.
