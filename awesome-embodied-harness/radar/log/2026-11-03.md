# Radar · 2026-11-03

## Signals

- **The harness is now designed by a coding model, and then distilled.**
  - RoboArchitect: a coding model watches a frozen policy's rollouts and repeatedly rewrites the control code around it, including the harness's own persistent memory. Average success on unseen scenes rises from 9.7% to 43.3%, and on unseen tasks from 12.7% to 40.2%, with no weight updates. The evolved harness often outperforms a fine-tuned policy (first-party).
  - TinyAstral evolves a teacher's harness with statistically gated edits (RoboTwin 33.4%→63.6%), then distills a 4B student that runs in the same harness at 62.8% (first-party).
  - CaPtain trains a code-as-policy model rather than its harness: SFT and then multi-turn RL with a privileged physical critic take Qwen3.5-4B from 0% to 55.4% (first-party, code and weights released). AgenticRoboRL (2026-10-20) took the same post-training route for the planner.
- **Runtime design for fast-and-slow control.** REA's rule is that no running policy waits on the "brain". It keeps a route memory of each policy's measured success, consults the brain at a judge gate when execution crosses task boundaries, and escalates within a shared budget (95.9% on 3,000 LIBERO-Pro episodes, first-party).
- **Experience as context, not weights.** LEXP adapts a frozen GPT-6 Astra on a real robot by extracting lessons with applicability conditions from its own executions (23/36 real trials versus 2/36 for vanilla Astra). SketchMate stores reusable geometric sketches, and BioAgent grows lab skills under explicit precondition and outcome checks.
- **Evaluation hygiene.**
  - SimuGuard traces many "policy failures" on RoboTwin to simulator collision artifacts that eject correctly placed objects.
  - A start-suppression study finds six VLA checkpoints start moving even with an empty instruction, and often complete a task nobody asked for.
