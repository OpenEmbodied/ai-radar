# Radar · 2026-11-19

## Signals

- **Many arms, real time, real cost.** In RoboTeam, agents control 4 to 16 robot arms in real time from camera images alone, on 36 long jobs such as passing timbers or building a picture from hundreds of cubes. With an adaptive system in which one agent decides when to fork delegates, gpt-6.1-sol and opus-5.5 complete 28 and 27 tasks, and four other models complete at most 3. A typical task takes gpt-6.1-sol 3.5 hours and 218 million input tokens (first-party). Hierarchical and decentralized systems run faster but use up to 1.9 times the tokens.
- **The world as the test suite.** An 83-page survey treats coding agents that write programs for robots, laboratories and industrial controllers as a new field. Unlike in software engineering, no test suite comes with the code: evidence that a program works must come from robots, simulators or the policies it trains, and that evidence is costly and can be wrong.
- **Turning VLAs into tools agents can steer.** InteractVLA lets an agent steer a VLA toward a chosen end-effector target and read the VLA's generated action chunks back to diagnose errors, instead of retrying a black box.
- **Where robot agents break.**
  - PAIR adds smart-home devices with both physical panels and APIs: fine-tuned VLAs complete none of 120 episodes, and even with oracle plans and API access most failures stall at navigation, grasping or doors (first-party).
  - A security study shows that an unauthenticated network attacker can rewrite the system prompt of an LLM-controlled social robot, changing its physical behavior where prompt injection had failed.
  - An audit of a learned legged-robot simulator finds that checks one step ahead misjudge design choices for 100-step rollouts.
- **Data and collaboration.** HubEgo-100K releases 10,124 hours of egocentric video of skilled work in 15,548 environments under CC BY 4.0. Heave-Ho coordinates up to ten humanoids through speech-based leader-follower signals, with no network messages between robots (code released).
