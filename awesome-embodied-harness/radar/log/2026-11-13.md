# Radar · 2026-11-13

## Signals

- **A world-action model with an agent interface.** NVIDIA's GR00T 2, announced at CoRL 2026 alongside Isaac Lab 3.0, predicts future video and robot actions together and runs on parallel grippers, dexterous hands and humanoids. NVIDIA reports the following (first-party):
  - 40% zero-shot success on 50 tasks never seen on the target robot, rising to 95% with five demonstrations per task;
  - skills that transfer from human video and handheld or wearable devices to robots;
  - a WAM API through which a reasoning model calls the policy, completing 97 or more of 100 back-to-back assemblies of each of three toys and recovering from stalls along the way.

  The project page lists code for December 2026. Weights are not public yet, and the 100K-hour egocentric human dataset is already on Hugging Face. This continues the harness-calls-policy pattern seen in AMP1 (2026-11-10).
- **Dropping the vision encoder.** NEO-VLA tokenizes pixels with lightweight convolutions inside a shared backbone, so the action expert can read visual features from several depths. The authors report that native, encoder-free architectures beat encoder-based ones; code and weights released.
- **Quiet arXiv day.** Thursday's arXiv listing had not been published when this run finished (checked until 01:28 UTC). It falls into the next run's window.
