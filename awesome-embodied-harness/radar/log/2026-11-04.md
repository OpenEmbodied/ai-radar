# Radar · 2026-11-04

## Signals

- **The harness wins on public leaderboards.**
  - Auriga is a task-agnostic harness, developed over 13 cross-task iterations and then frozen. The model decides over an explicit task belief and acts through tool calls or synthesized Python. It previews trajectories before moving and stops on tolerance violations to recover in place. It ranks first on RoboDojo at 57.7%, more than double the reference harness with the same model, and stays first under scene randomization while learned policies drop by up to 33.9% (first-party).
  - uni-robot-agent is an open, trainable harness. With it, out-of-the-box Qwen3.8-Flash-Next scores 31.39 on RoboDojo, above a published GPT-6 Astra result of 28.97 (first-party).
- **The VLM's job shifts from emitting actions to building a model of the world.** WorldSketch has the VLM build and visually validate a minimal kinematic world model, which a geometric planner optimizes over. It reports 91% on RoboCasa and 97% on LIBERO-PRO zero-shot with 10× fewer VLM tokens than the next agent (first-party). TAMPAgent has an LVLM write partial TAMP plans that classical search completes.
- **Agentic fleets have a systems problem.** Serving robots that each pair a VLM brain with a VLA is limited by KV-cache thrashing: brain contexts reach 215k tokens, and throughput collapses as the fleet grows unless active episodes are capped. Late Autumn has coding agents specialize one warehouse's multi-robot planner, raising throughput 22–60% (first-party) through reviewable commits, though some patches multiply compute by 100×.
- **Evaluation at scale disagrees with itself.** RoboColosseum's 5,699 blinded pairwise trials at 124 sites find frontier agents rival specialized VLAs. Rankings agree poorly across embodiments (Kendall W = 0.24), and zero-shot rankings poorly predict post-fine-tuning results. "When Delay Meets Drift" shows a 400 ms delay plus a camera shift raises safety violations far more than the two effects add up to.

## Added

- **Auriga** (harness): a task-agnostic agent harness for zero-shot manipulation, first on RoboDojo; code released. [paper](https://arxiv.org/abs/2611.01112)
- **uni-robot-agent** (harness): a unified harness for open-weight robot-use agents; code released. [paper](https://arxiv.org/abs/2611.01560)
- **WorldSketch** (harness): the VLM sketches a world model rather than actions. [paper](https://arxiv.org/abs/2611.00513)
- **TAMPAgent** (harness): agentic belief-space TAMP for mobile manipulation. [paper](https://arxiv.org/abs/2611.03584)
- **RoboColosseum** (benchmark): distributed in-the-wild evaluation across 124 sites. Not the same as RoboColiseum (Agent2Act). [paper](https://arxiv.org/abs/2611.02497)
- **Serving Agentic Robot Fleets** (framework): workload characterization and admission control. [paper](https://arxiv.org/abs/2611.01404)
- **LIFE (Learning to Live)** (memory): streaming gates, plastic memory and self-made tools for lifelong robots. [paper](https://arxiv.org/abs/2611.00180)
- **Do Embodied VLMs Use Their Scene-Graph Memory?** (memory): a graph-swap reliance test. [paper](https://arxiv.org/abs/2611.02056)
- **Late Autumn** (multi-agent): coding agents specialize a warehouse multi-robot planner. [paper](https://arxiv.org/abs/2611.02391)
- **When Delay Meets Drift** (safety): physical safety as a cross-layer problem. [paper](https://arxiv.org/abs/2611.02101)
- **CalVLA** (verification): native VLA confidence shaped by outcome supervision. [paper](https://arxiv.org/abs/2611.00394)
- **D&A (Describe & Assess)** (verification): decoupled description and assessment for zero-shot VLM reward models; code released. [paper](https://arxiv.org/abs/2611.03622)
