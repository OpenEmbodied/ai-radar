# Radar · 2026-11-26

## Signals

- **The seam between agent and policy, engineered.** Three papers make explicit the point where an orchestrating agent hands control to a learned policy (all first-party):
  - **Boundary-Aware Policy Learning** trains a policy to be reliable from a wide, well-defined set of start states, its "handoff boundary", and then widens that set with successful system rollouts. It reaches 98.4% in randomized RoboTwin 2.0 scenes, more than 26 points above the strongest baseline, with 41.3% lower API cost.
  - **VLAs Execute, Code Recovers** measures the 3D volume each frozen skill sweeps and gives the agent CHECK and FREE tools built from it, lifting 3- to 4-step drawer chains with frozen π0.5 from 29.7% to 93.8%.
  - **EmboEagle**, promoted from the queue, gates VLM supervision adaptively, cutting VLM calls by 74.2%.
- **One demonstration, verified world, transferable code.** RESET rebuilds a simulated world and a frozen success criterion from a single real demonstration, and checks the world by replaying the demonstration. A coding agent then improves white-box skill code inside that world. The frozen programs succeed in 80% of 280 real trials on 4 robots, and robots with similar arms reuse 95% of the source robot's skill functions unchanged (first-party).
- **Open models catch up through agentic RL.** RoboHarness-RL trains Qwen3.5-9B to manipulate robots through tool calls, raising LIBERO-Pro success from 57.8% to 73.3% with up to 4× fewer repeated calls (first-party). OmniAct trains one policy across a million simulated robot bodies, and beats GPT-6 Astra on the task families where both were tested.
- **Benchmarks keep finding blind spots.** All figures first-party.
  - **ICLWorld:** the same frontier agents that learn new rules in 76% to 82% of computer-use runs manage only 26% to 27% in robot-use runs.
  - **The mirror test:** placing a mirror in the scene costs policies 10.8 to 56.7 points on average, mostly from reaching for reflections rather than collisions.
  - **DeCoNav-Act:** even GPT-6.1-sol completes only 4.1% of tasks that require one robot to leave the world usable for a teammate.
  - **EmbodiSafety:** the best model makes a completely correct safety decision in only 56% to 62% of cases.

## 中文速览

今日新增 12 条，排队 11 条。主线是"把智能体与策略之间的交接点显式化"：Boundary-Aware Policy Learning 先训练策略在一个宽而明确的起始状态范围内可靠工作，再用成功的系统运行结果扩大这个"交接边界"，在随机化的 RoboTwin 2.0 场景中达到 98.4%，比最强基线高 26 个百分点以上；另一项工作测量每个冻结 VLA 技能成功执行时扫过的三维空间，作为 CHECK 和 FREE 两个工具交给智能体，把 3 到 4 步的抽屉任务链成功率从 29.7% 提高到 93.8%。RESET 只用一次真实示范重建并验证仿真世界，再让编码智能体在其中改进技能代码，在 4 台机器人上的 280 次真机试验中成功率为 80%（均为作者自报）。评测方面，ICLWorld 发现前沿智能体在电脑任务中能学会新规则（76% 到 82%），在机器人任务中却只有 26% 到 27%；在场景中放一面镜子，就会让各类机器人策略的成功率平均下降 10.8 到 56.7 个百分点。
