# Radar · 2026-11-20

## Signals

- **The sim-to-real gap, measured on agent-designed robots.** In RoboBuilder, coding agents co-design a robot's hardware and program from standard parts, motors and a custom 3D-printed part. Every design that passes in simulation is built and run on a physical course. The authors report (first-party, code released):
  - Using only public part data, none of 15 initial passing designs crossed the real course.
  - Across 135 physical robots, only 66% of simulated passes hold.
  - Shown a video of its real failure, an agent redesigns the robot, sometimes correcting its simulator, and removes 72% of level-1 and level-2 failures.
- **Passing the check is not finding every bug.** RoboDx injects faults into robot navigation software and verifies each repair by hidden driving tests. Almost every repair by Claude Opus 5.5 is verified. Yet on 50 two-fault tasks, only 17 of 49 verified repairs remove both faults; most of the faults left behind are configuration constants that the documentation never states. Diagnosing the cause from measurements alone, models name it on at most 38 of 94 tasks (first-party).
- **Keeping VLAs on track over long tasks.**
  - RePlan-VLA leaves the VLA unchanged and wraps it in progress monitoring and replanning, scoring 21.9 points above the next baseline on RoboCasa365 (first-party).
  - GTI conditions the VLA on visual targets for the current phase of the current subtask, and rolls back and re-observes when execution deviates.
  - NVIDIA's Grana reward model scores progress subtask by subtask, using open-vocabulary subtask descriptions.
- **Self-improvement and robustness.**
  - AeroRSI has a drone navigation policy judge candidate repairs by flying on from its own failure states, raising TravelUAV success from 46.4% to 67.5% over three rounds (first-party, code released).
  - RECLAIM uses a frozen VLA's own attention to locate and clean adversarial patches, recovering LIBERO-Object from 0% to 70.0% under attack (first-party).
